Case study / Data visualization

欧洲卫浴数据看板：把五国站点与新品机会变成可读的分析面板

这类项目最能体现“数据分析”能力：不是简单抄表，而是把多国家站点、多个品类和新品情况压缩成一个能让团队快速看懂的可视化结构。对业务来说，这种看板比长篇报告更适合做阶段性判断和优先级决策。

Project Snapshot

  • 研究对象欧洲亚马逊卫浴市场动态
  • 分析维度

    站点规模、新品占比、国家差异、品类机会、产品开发提示。

  • 交付形式

    适合业务和产品共用的数据看板，而不是只给分析岗自己看的原始表。

  • 能力证明

    体现我具备把 Excel 复杂信息转成“业务可读界面”的能力。

欧洲站不能一概而论。德国是最大市场，英国次之，法国、西班牙、意大利明显更小。

新品数量占比本身就是市场友好度信号。不是新品越多越好，而是要看新品能不能起量。

德国

新品 362 个，占比 5.7%

新品友好度较高，且单 SKU 产值更优，值得优先观察。

英国

新品 271 个，占比 5.6%

与德国接近，但均价更低，适合观察爆款花洒路径。

法国 / 西班牙 / 意大利

新品占比逐步下降

体量较小，更适合在主站点跑通后做延展，而不是优先切入。

总体

新品数 977，占比约 5.0%

说明欧洲站对新品并不封闭，但依然需要明确站点与品类顺序。

当我把国家看完后，会立刻收束到“优先做什么品类”。因为只有品类层面清楚了，开发和供应链才能接得上。
